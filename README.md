# Kodme Desktop

**Kodme Desktop** — десктоп-обёртка мессенджера **«Код.me»** на
[Electron](https://www.electronjs.org): приложение открывает
[kodme.ru](https://app.kodme.ru) в отдельном окне, запоминает его размеры и
положение, показывает нативные уведомления системы и открывает внешние
ссылки в системном браузере.

Вся логика клиента живёт на сайте платформы — обёртка добавляет только
десктопную интеграцию: собственное окно, уведомления и изоляцию страницы
(`contextIsolation: true`, `nodeIntegration: false`).

Исходники этого репозитория публикуются из основного репозитория платформы
скриптом публикации — источник истины там, здесь фиксируется релиз.

## Ссылки

## Сборка под свой сервер

Адрес платформы — константа `APP_URL` в начале `main.js`: замените её на
свой домен (на неё завязаны и загрузка окна, и проверка внешних ссылок),
затем соберите приложение по инструкции ниже.

## Требования

- [Node.js](https://nodejs.org) 22+ с npm — зависимости и сборка;
- (опционально) [Podman](https://podman.io) — сборка в контейнере `./build.sh`.

## Сборка

```bash
npm install      # зависимости
npm start        # запуск приложения
npm run dist     # дистрибутивы → dist/ (AppImage, deb, rpm; Windows — NSIS)
```

Либо сборка в контейнере без локального Node/npm:

```bash
./build.sh
```

`./build.sh` очищает `dist/` и `node_modules/` перед сборкой — это
ожидаемо.

## Релизы

Каждая публикация исходников в этот репозиторий сопровождается вопросом о
версии — она записывается в `package.json` и коммитится. После пуша GitHub
Actions (`.github/workflows/release.yml`) собирает дистрибутивы и публикует
**GitHub Release** с тегом `vX.Y.Z`: ассеты `AppImage`, `deb`, `rpm`
(Linux) и установщик Windows. Если релиз с такой версией уже существует —
ничего не пересобирается и не перезаписывается.
